## About

superfile is a modern, feature-rich TUI file manager. It puts several file
panels side by side, with a sidebar of pinned and well-known directories, a
metadata panel, a preview pane and a processes bar that tracks long-running
copy, move and delete operations while you keep working.

It supports fuzzy search, batch renaming, archive extraction and compression, a
built-in trash bin with restore, Git status indicators, image previews (kitty
graphics protocol), video and PDF previews, and zoxide-backed directory
jumping. Themes, hotkeys, the panel layout and the sidebar sections are all
configurable.

**The command is `spf`, not `superfile`.**

Run `spf` to start it, `spf --help` for the command reference and
`spf path-list` to print the paths of the configuration and data directories.

**[Read the documentation](https://superfile.dev)**
